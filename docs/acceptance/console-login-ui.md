# 登录页视觉改造记录

日期：2026-09-11。经设计访谈、隔离原型和两次角标调整确认后实施。权威规则在 [Design System 规范](../25-design-system.md)，本记录不创建第二套规范。

## 实现范围

Platform 与 Tenant Console 共用 `LoginLayout`：居中卡片、平台品牌、系统名称右上角的入口角标、40px 输入与全宽登录按钮、页面右上角的唯一语言入口。密码使用既有 PasswordField 的眼睛图标；显示状态与键盘能力沿用组件。英文平台角标为 Platform admin，避免长单词撑开窄屏。

登录的成功、会话冲突、Tenant 不可访问与通用错误提示继续使用原逻辑，放在标题与表单之间。窄屏提示动作另起一行，长错误码允许换行。登录按钮悬停保持品牌前景色对，避免默认提亮后白字对比度不足。

没有新增认证功能，没有改变密码清理、请求取消、会话槽、登录回跳或首次改密/选择 Context 的状态逻辑；相邻页面只做现有回归。没有新增依赖、公开 UI 包或独立业务术语，因此未另建 ADR/词汇定义。

## 验证

- Design System 与 React Shell 类型检查、根浏览器测试类型检查、相关 lint 通过。
- Design System 73 项、React Shell 33 项单元测试通过，包含既有语言切换保留输入/焦点、进行中登录、密码清理和认证状态回归。
- `pnpm run build:workspace` 通过，其中包含国际化校验、单一全局 CSS 及按需制品边界检查；现有大 chunk 提示保留。
- 新增 5 项真实组件浏览器夹具：两个入口的浅色/深色、精确错误分支、密码图标键盘切换、提交后密码清理、320px 无横向溢出、axe 对比度与英文语言切换保留输入。
- Chromium 消费者测试共 19 项（含新旧截图）；截图人工检查了默认登录、会话冲突、Tenant 长错误、英文角标和窄屏布局。
- 桌面 Chrome 消费者检查 17 项通过，2 项截图矩阵按 `SF_VISUAL_SNAPSHOTS=false` 跳过；Chromium 普通截图比较复验 19 项通过。
- 正式 `https://console.saasforge.test/login` 已在用户启动的环境中打开，深色卡片、Logo、入口角标、语言控件与密码图标显示正确。

## 边界

浏览器夹具通过受控 HTTP 响应进入真实 React Shell 的错误分支，不是真实后端登录验收。本轮未使用真实凭据提交登录，未主动退出用户现有 Platform 会话，未运行 Fresh Compose 或完整认证安全矩阵。
