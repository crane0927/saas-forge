# 数据库、Redis 与应用日志以版本化规范和 CI 门禁治理

数据库结构、Redis Key 和应用日志都是跨版本运行契约，却不能通过共享领域实体或数据库模型获得一致性。项目因此以人读规范解释边界和取舍，以 Flyway、Redis Registry、日志 Schema 与策略表达机器可校验部分，并把校验接入统一的 Maven `verify` 门禁；服务之间只共享版本化 API、事件及非领域基础设施契约，各自拥有领域模型、持久化模型、数据库和迁移。这避免公共 `BaseEntity`、Mapper 或共享表形成隐式耦合，同时允许 SDK 提供 Tenant Context、缓存接口和可观测性能力，业务项目仍在自己的数据库所有权边界内选择持久化实现。
